# Projeto de Análise de Encomendas

## 📌 Descrição

Este projeto foi desenvolvido em Python para validar, processar e analisar dados de encomendas armazenados num ficheiro CSV.

Os dados são posteriormente inseridos numa base de dados PostgreSQL, onde são realizadas várias consultas SQL para obter informações sobre as vendas, produtos, países e clientes.

## 🛠️ Tecnologias utilizadas

- Python
- CSV
- PostgreSQL
- SQL
- pgAdmin 4
- Psycopg
- Git
- GitHub
